## 与此前听音版本的关系

原始项目已经由使用者确认：100 ms 模式两台连续出声，150 ms 模式也能出声。50 ms 曾发生会话正常却无声，已经从可选模式移除。

`engine.py`、`latency.py`、`realtime.py`、`volume_control.py` 从最后一次 100 ms 版本保留。公开整理主要变更：

1. 将固定设备 ID 改为用户本机 `config.json`；默认按组主机选择，也可指定已验证的入口。
2. 从用户指定的两台设备中发现、选择及生成受限防火墙规则。
3. 移除对原临时工作区的依赖以及旧进程迁移逻辑，改为标准虚拟环境构建。
4. 从自动退出 TuneBlade 改为提示使用者自行退出。
5. 新增中文安装、配置、重装、故障排查及构建文档。

**公开配置版没有重新进行真实双箱听音测试或 GUI 操作验证。** 本次自动化结果不证明其他 HomePod、固件、网络或任意 AirPlay 接收器一定可用，也不构成 100 ms 端到端延迟的测量。

抓包、录音、真实设备 ID、IP、发现缓存、日志及旧定制版二进制都未提交到公开仓库。
